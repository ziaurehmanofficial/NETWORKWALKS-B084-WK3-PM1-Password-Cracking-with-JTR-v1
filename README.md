## 📌 Project Overview

This project was completed as part of the Cybersecurity & Ethical Hacking program at Networkwalks (Batch B084).

The project focuses on understanding password cracking techniques by recovering the password of a protected PDF file using two different approaches: **John the Ripper (JTR)** and **Networkwalks online tools**.

Through these practical exercises, I learned how to extract password hashes from encrypted PDF files, perform dictionary-based password cracking, and understand the importance of strong passwords.

## 🎯 Project Objectives

- Understand the basics of password hashing and cracking.
- Extract password hashes from protected PDF files.
- Practice password recovery using John the Ripper.
- Explore the Johnny graphical interface.
- Use Networkwalks Hash Calculator and Password Cracker.
- Understand dictionary-based password attacks.
- Learn why strong passwords are important for security.

## 🔍 Module 1: Password Cracking with JTR

**Tools:** John the Ripper and Johnny GUI

### Practical Tasks Completed

- Downloaded and configured John the Ripper.
- Installed and opened the Johnny graphical interface.
- Configured Johnny to locate the `john.exe` executable.
- Uploaded the provided encrypted PDF to an online PDF Hash Extractor.
- Extracted and copied the PDF hash.
- Saved the hash in a text file named `hash1.txt`.
- Imported the hash file into Johnny.
- Started the password-cracking process.
- Recovered the PDF password.
- Successfully opened the protected PDF using the recovered password.

## 🌐 Module 2: Password Cracking with Networkwalks Tools

**Tools:** Networkwalks Hash Calculator and Password Cracker

### Practical Tasks Completed

- Downloaded the provided encrypted PDF file.
- Opened the Networkwalks Hash Calculator.
- Uploaded the protected PDF file.
- Extracted the PDF hash starting with `$pdf$`.
- Copied the complete hash value.
- Opened the Networkwalks Password Cracker.
- Pasted the extracted hash into the tool.
- Used the built-in password list to perform a dictionary attack.
- Waited for the cracking process to complete.
- Recovered the password and opened the protected PDF.
